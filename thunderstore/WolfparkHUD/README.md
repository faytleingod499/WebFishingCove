# Wolfpark HUD

The player panel for **Ether's Wolf Park** and other servers running the Cove **Feed** plugin.

*This mod was created with the assistance of AI.*

It adds a small panel at the top left with:

- your **wolf coin** balance,
- a **Feed Wolves** button,
- a **Buy** menu listing everything the server sells,
- a bet box with a **Gamble** button,
- a **Leaderboard** button.

Drag the `::` handle to move the panel; it remembers where you put it. Commands you type starting with `!`
go to the server only and don't show in chat. Server messages show in their own colour, and the chat
window starts expanded.

While you're on the server you can also wear the titles **Lonely** and **Battery Charger** (Cosmetics, Misc tab).
They're taken off again when you leave.

## For admins

Server admins get a small shield button to the left of the title. It opens a list of everyone on the server
(except the host) under the panel, with **Kick** and **Ban** beside each name. Ban asks for a second click
("Sure?") so it can't happen by accident. The buttons use the server's own kick and ban commands, so the
server still checks that you're an admin.

## Other servers

The panel only appears on servers that run the Feed plugin. Everywhere else the mod stays hidden and does
nothing, so it's safe to leave installed.
